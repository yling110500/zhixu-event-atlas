# 知序 · 投资事件证据台

[打开产品](https://event-evidence-atlas-ly-1030.yao074015.chatgpt.site/) · [观看演示视频](https://github.com/yling110500/zhixu-event-atlas/blob/main/demo.mp4) · [源码仓库](https://github.com/yling110500/zhixu-event-atlas)

面向个人投资研究者，将同一事件的公告、材料、证据与结论变化串成可回看的时间线。选题：投资事件情报与证据时间线。

## 评审快速体验

1. 打开演示站，即可在事件台上传材料或粘贴正文。
2. 下载[验收资料包](知序验收资料.zip)，按其中的指南依次上传01、02、03，检查同一重组事件从筹划、预案到终止的变化。
3. 上传04分红材料，检查系统是否把同一公司的另一事项独立建档。具体标题、措辞和中间分类可能变化；待确认的归并需要人工核对。
4. 从左侧“历史研究”重新打开个人事件，在“版本”回看旧结论，在“调用记录”核对真实模型和用量。“示例案例”是单独标注的人工核验记录。

无需ChatGPT账号。游客资料与当前浏览器的会话关联，刷新可恢复；换浏览器、清除Cookie或会话过期后无法自动找回。每个游客空间每天10次，全站每天50次。额度耗尽仍可浏览历史与已有资料。

## 产品设计与AI职责

目标用户是持续跟踪少量公司的个人投资研究者。核心价值是看清同一事件的最新状态、改变了什么、结论来自哪份材料。DeepSeek负责语义抽取、公司与事项识别、事件归属建议、陈述类型和证据关系分析；程序负责格式与引用验证、时间处理、版本保存、空间隔离与并发控制。模糊归并和无法确定先后的状态变化需要人工确认。

真实历史样例为海光信息与中科曙光合并筹划、预案、终止，以及独立分红四份公告。展示人工核验摘要、必要短引、官方链接和页码，不把人工样例冒充AI结果。

## 验证结果与边界

49项自动测试、类型检查与生产构建通过。公开站点已实际验证游客空间、资料保存、真实DeepSeek调用、失败保护、重试、独立分红归类与持久化。2026-10-31约10:00的NVIDIA新案例一次生产分析成功：deepseek-flash、提示词1.1、2.8秒、1355 tokens；剩余额度10变9，新增后共3个事件且刷新保留。以上为单次观察，不是准确率或性能统计。

原型不自动抓取全网，不解析PDF，不执行交易，不提供收益预测。引用验证仅核对输入文本，不证明材料真实或摘要语义完全正确。缺失时间保持未知；未记录的用量不编造。评审自己的网络环境仍需以实际访问为准。
